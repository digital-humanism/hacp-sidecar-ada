# Ada Comparison Surface

The Ada implementation is already repository-owned by `hacp-sidecar-ada`.

This directory is reserved for `t_rs`-specific Ada comparison orchestration.

Stable implementation, vectors, harness, project files, environment discovery,
and build preparation are reused in place when no modification is required.

The existing `t_ada` matrix is not modified.
Its previously recorded verdicts are not substituted for a fresh `t_rs` run.
